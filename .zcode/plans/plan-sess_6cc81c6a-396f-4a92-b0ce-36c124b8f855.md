# nes-compat：ROM 库浏览 + 兼容性测试客户端

## Context

用户在用 13.9 万条 ROM 元数据数据库 `roms/nes-games.db`（game/rom/nsf/mapper_name 表）做 nes-sim 模拟器的 ROM 兼容性实测。现有前端（minifb 单窗口 nes-desktop、web demo）都没有库浏览、结果记录能力。需要一个本地客户端：浏览/检索数据库 → 按需从 `roms/游戏rom/ever/<game_id>.7z` 流式解压单个 ROM（**不全量解压**）→ 内嵌运行 → 人工标记兼容性结果，另加无人值守批量冒烟测试。结果存独立库 `roms/compat.db`（nes-games.db 是 `tools/build_game_db.py` 的可再生产物，不可写）。

## 方案总览

新增两个 workspace 成员 crate：

1. **`nes-audio`**（小工具 crate）：把 nes-desktop 中的 `AudioPlayer` / `AudioOutputState` / `StreamingLinearResampler` / `write_audio_data*`（`nes-desktop/src/main.rs:910-1244`，约 350 行）和对应单测（`nes-desktop/src/tests.rs`）原样迁移过来，仅依赖 cpal。nes-desktop 改为依赖它，避免与 nes-compat 重复。
2. **`nes-compat`**（本次主体）：egui 桌面应用 + CLI。

`nes-compat` 依赖：`nes-sim`（workspace）、`nes-audio`（path）、`eframe/egui`（实现时取最新稳定版）、`rusqlite`（bundled）、`serde` + `toml`（配置）、`rfd`（路径选择）。

## nes-compat 模块设计

### `archive.rs` — 7z 按需解压
- 7zz 发现顺序：配置项 > PATH 中 `7zz`/`7z`（本机有 `/opt/homebrew/bin/7zz`）
- `list(game_id) -> Vec<条目>`：`7zz l -slt ever/<id>.7z`，解析文件名/大小，按 game_id 内存缓存（NSF 在包内 `#音乐/` 前缀，与 nsf.fname 两套命名规范，用归一化匹配：小写、去路径前缀）
- `extract(game_id, 内部路径) -> Vec<u8>`：`7zz e -so <包> <内部路径>` 捕获 stdout（与 build_game_db.py 同款流式方案）

### `db.rs` — nes-games.db 只读访问（rusqlite，SQLITE_OPEN_READ_ONLY）
- 游戏列表：搜索（name_cn2/name_en2/name_jp/rom.fname LIKE）+ 筛选（mapper、type1、仅未测试），分页；9,481 个游戏用 egui `ScrollArea::show_rows` 渲染
- 游戏详情：game 行 + 该 game_id 的 rom 列表（fname/mapper/prg/chr/size/md5）+ nsf 列表
- mapper 联表 mapper_name 取名称与 supported 标记
- “下一个未测试”：rom LEFT JOIN result IS NULL 随机/按 mapper 取一条

### `compatdb.rs` — 结果库 `roms/compat.db`（WAL）
```sql
CREATE TABLE result (key TEXT PRIMARY KEY, kind TEXT, fname TEXT, game_id INTEGER,
  status TEXT, note TEXT, source TEXT, updated_at TEXT);  -- key=rom.md5/nsf.md5
CREATE TABLE smoke_log (key TEXT PRIMARY KEY, frames INTEGER, elapsed_ms INTEGER,
  distinct_colors INTEGER, audio_energy REAL, frozen INTEGER, detail TEXT, updated_at TEXT);
```
- status：`ok / minor / major / broken`（人工）+ `load_error / skip / blank / frozen / smoke_ok`（自动）；source：`manual` 永远优先于 `smoke`，自动结果不覆盖人工记录

### `player.rs` — 模拟器线程
- 专用线程拥有 `FrontendRuntime` + `AudioPlayer`：循环取共享输入 → `runtime.step(input)` → `frame_to_rgba_with` 写入 `Arc<Mutex<Vec<u8>>>` 最新帧 + `ctx.request_repaint()` → 音频入队 → 按 NTSC 16.639ms / PAL 19.997ms deadline 步进（快进跳过等待并停用音频，同 nes-desktop 逻辑）
- 输入：`Arc<Mutex<PlayShared>>`（P1/P2 键位同 nes-desktop：方向键+Z/X+Shift/Enter；egui 焦点问题故 Select 用 Shift 替代 Tab，并提供屏幕虚拟手柄按钮）；mpsc 命令：Load(rom 字节+元数据)/Stop
- 复用 `nes-desktop/src/main.rs` 的加载辅助逻辑：电池存档、FDS BIOS 查找（配置路径优先，无 BIOS 的 FDS 明确提示）、FDS 磁盘热键

### `smoke.rs` — 批量冒烟（GUI 线程与 CLI 共用）
对每个 ROM：解压 → `FrontendRuntime::from_rom_bytes_with_bios` → 跑 N 帧（默认 300）→ 记录：
- 解压失败 → `skip`；`CartridgeError` → `load_error`（区分 `UnsupportedMapper(n)`、裸 dump InvalidMagic、FDS 无 BIOS skip）
- 末帧调色板索引去重色数 ≤2 → `blank`；帧计数推进但中段/末帧 `stable_byte_hash` 相同 → `frozen`（用 `nes_sim::headless::stable_byte_hash`）
- NSF：黑屏属正常，信号改为音频能量 >0
- 耗时 ms 写 smoke_log；顺序执行 + AtomicBool 取消 + 进度/ETA；默认排除裸 dump（mapper IS NOT NULL）

### `app.rs` — GUI 界面（中文）
- **游戏库**：搜索/筛选栏 + 游戏列表（名称/英文名/公司/年份/类型/ROM 数/已测 n/m）
- **游戏详情**：元数据 + ROM 表（运行按钮、结果徽章）+ NSF 表（播放）+ 本游戏全部冒烟
- **NSF 库**：按曲名/艺术家/扩展音源检索播放
- **冒烟测试**：范围（mapper/当前筛选集）、帧数、开始/停止、进度条、结果表、汇总计数
- **统计**：按 mapper GROUP BY 的 总数/已测/各级结果 + supported 标记
- **播放视图**：画布（256×240 NEAREST 缩放）+ HUD（fps/mapper/制式/文件名）+ 底部快速标记栏：✅正常 ⚠️小问题 ❌严重 💀无法运行 + 备注 + **下一个未测试 ▶**（核心工作流：玩→标→跳下一个）
- **设置**：db/ever/7zz/FDS BIOS 路径，持久化到 `roms/compat.toml`（roms/ 已被 gitignore）

### CLI（`main.rs` 手写参数解析，风格同 nes-desktop）
- `nes-compat` → GUI
- `nes-compat smoke --mapper N | --game-id ID | --all --frames 300 --limit K [--untested-only]` → 无窗口批量跑，写 compat.db（可过夜）
- `nes-compat stats` → 终端打印按 mapper 的兼容性汇总表

## 实施步骤

1. 新建 `nes-audio` crate，迁移 AudioPlayer 系代码与单测；nes-desktop 改 lib 依赖并 `cargo test -p nes-audio -p nes-desktop` 验证纯代码搬移
2. 新建 `nes-compat` 骨架（config/db/archive 三模块 + 单测：归一化匹配、compatdb CRUD、7z 往返——按 `read_optional_binary_fixture` 惯惯例缺包即跳过）
3. player.rs 模拟器线程 + 播放视图，先跑通「列表→详情→运行」
4. 标记栏 + compatdb + 下一个未测试
5. smoke.rs + 冒烟视图 + CLI 子命令
6. 统计视图、NSF 库、设置视图收尾

## 验证

- `cargo test -p nes-audio -p nes-compat` 全绿
- `cargo run -p nes-compat --release`：搜“魂斗罗”→ 详情列出多版本 ROM → 运行可玩 → 标记“正常” → `sqlite3 roms/compat.db 'select * from result'` 有行
- `cargo run -p nes-compat --release -- smoke --game-id <某id> --frames 120`：产出 load_error/blank/ok 分类，`stats` 汇总正确
- NSF 播放一条（`#音乐` 解压路径验证）；FDS 无 BIOS 时明确 skip 提示；确认 never 触发全量解压（仅 `7zz e -so` 单文件流）
